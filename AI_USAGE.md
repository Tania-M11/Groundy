## 3. AI-assisted software evaluation and interface refinement

**Claude Code (Anthropic)** was used during the software evaluation and refinement phase. Its involvement was based on the existing project structure and a technical planning document prepared by the Potatonauts team.

The team provided the established application structure and a document specifying the planned functionality, component responsibilities, expected behavior, and implementation requirements. Claude Code used these materials as the reference for evaluating the software.

Its contributions included:

- **Functional evaluation:** Reviewing and testing the implemented components across different usage scenarios to verify that their behavior matched the requirements and workflows defined by the team.
- **Requirements verification:** Checking whether the implemented functionality operated as specified in the team's technical planning document and identifying inconsistencies or unexpected behavior.
- **Interface implementation review:** Comparing the implemented interface against design templates provided by the team through Canva.
- **Code corrections:** Identifying and correcting errors in the interface code where the implementation did not properly reproduce the supplied designs.
- **Responsive design evaluation:** Testing the interface across different screen sizes and resolutions, identifying layout issues, and correcting responsive behavior to ensure usability on desktop, tablet, and mobile devices.

Claude Code therefore served as a technical evaluation and refinement tool, working from the team's predefined requirements and design references. The functional scope, component specifications, design references, and intended behavior were established by the Potatonauts team.

## 4. Potatonaut (the assistant inside Groundy)

Potatonaut is the conversational assistant integrated into the Groundy web application. It consumes the team's conversational service, **Papanauta** (`https://papanauta.groundy.site`, `POST /chat/papanauta`).

Each question is sent with the coordinates of the plot being viewed (plot centroid, explored point, or an example location in Ipiales when no plots are available) and, when applicable, the active crop.

Responses are generated by the Papanauta service and displayed as returned. The web application does not modify the generated answers.

The numerical data presented in Groundy's analysis panels comes exclusively from the Groundy API and its integrated data sources: NASA POWER, GPM IMERG, MODIS, SMAP, SRTM, Sentinel-2, and FAO EcoCrop.

## 5. Team responsibility and AI use

Artificial intelligence tools were used as supporting resources throughout specific stages of development. Their use does not replace the team's work in defining the project, establishing requirements, making technical and design decisions, selecting data sources, determining the scientific approach, or defining the intended functionality.

The Potatonauts team is responsible for the project's conception, technical planning, integration, and final implementation.
