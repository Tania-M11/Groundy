## AI-assisted software engineering
AI coding assistance (Claude Code, Anthropic) was used to scaffold the web application, write UI components,
and structure documentation. Product decisions, the choice of data sources, the scientific approach and the
validation of results belong to the Potatonauts team.

## Potatonaut (the assistant inside Groundy)
The chat in the web app consumes the team's conversational service **Papanauta** (`https://papanauta.groundy.site`,
`POST /chat/papanauta`). Each question is sent with the coordinates of the plot being viewed (plot centroid, explored
point or an example location in Ipiales when there are no plots yet) and, when there is one, the active crop.
Answers are generated by that service and shown as written; the web app does not alter them. The numbers shown in the
analysis panels come only from the Groundy API (NASA POWER, GPM IMERG, MODIS, SMAP, SRTM, Sentinel-2, FAO EcoCrop).
